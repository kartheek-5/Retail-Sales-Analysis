
# Retail Sales Analysis Dashboard

## Project Overview
This project focuses on analyzing retail sales data to understand business performance, product sales, customer purchasing patterns, and order status using Microsoft Excel, SQL, and Power BI.

## Project Objectives
- Analyze overall retail sales performance.
- Identify top-performing products.
- Compare sales across different cities.
- Analyze monthly sales trends.
- Track delivered, cancelled, and returned orders.
- Understand sales performance across different channels.

## Tools and Technologies
- Microsoft Excel – Data cleaning and preparation.
- SQL – Data querying and analysis.
- Power BI – Interactive dashboard and visualization.

## Dashboard KPIs
- Total Sales
- Total Orders
- Average Order Value
- Cancelled Orders
- Returned Orders
- Delivered Orders

## Dashboard Visualizations
- Sales by Category
- Monthly Sales Trend
- Top 5 Products by Sales
- Sales by City
- Sales by Channel

## Dataset
The project uses a retail sales dataset containing 100 records with order dates, products, categories, cities, quantities, discounts, payment methods, order statuses, and net sales.

## Key Learnings
- Data cleaning and preparation.
- SQL-based data analysis.
- Creating interactive Power BI dashboards.
- Building KPIs and business visualizations.
- Understanding sales trends and business performance.
